# Telegram Bot с Yandex GPT

Telegram-бот с поддержкой структурированных ответов от Yandex GPT в форматах JSON, XML и красивом текстовом представлении.

## Возможности

- **Три режима вывода:**
  - TEXT - красивое форматирование с иконками (по умолчанию)
  - JSON - структурированный вывод в JSON формате
  - XML - структурированный вывод в XML формате
- **Тестирование температуры LLM:**
  - Сравнение результатов работы модели при разных значениях temperature
  - Автоматический анализ креативности и стабильности ответов
  - Рекомендации по выбору оптимальной температуры для задачи
- Динамическое переключение между режимами для каждого пользователя
- Парсинг ответов с 3-уровневой стратегией fallback
- Валидация структурированных данных
- Полное логирование и обработка ошибок

## Требования

- Python 3.10 или выше
- Telegram Bot Token (от [@BotFather](https://t.me/BotFather))
- Yandex Cloud API Key с доступом к Yandex GPT

## Быстрый старт

### 1. Установите зависимости

```bash
pip install -r requirements.txt
```

### 2. Настройте переменные окружения

Создайте файл `.env`:

```env
TELEGRAM_TOKEN=ваш_telegram_bot_token
YANDEX_API_KEY=ваш_yandex_api_key
YANDEX_FOLDER_ID=ваш_yandex_folder_id
```

### 3. Запустите бота

```bash
python bot.py
```

### 4. Протестируйте в Telegram

```
/start              - Начать работу с ботом
/help               - Справка по командам
/text               - Переключить на текстовый режим (по умолчанию)
/json               - Переключить на JSON режим
/xml                - Переключить на XML режим
/status             - Показать текущий режим
/test_temperature   - Тестирование разных температур LLM
```

### Тестирование температуры LLM

**Что такое температура?**

Температура (temperature) — это параметр LLM, который контролирует степень случайности и креативности в ответах модели. Чем выше температура, тем более разнообразные и креативные ответы генерирует модель.

#### Использование команды

```
You: /test_temperature
Bot: [Тестирует с дефолтным промптом "Придумай название для стартапа по доставке еды"]

You: /test_temperature Придумай слоган для кофейни
Bot: [Тестирует с вашим промптом]
```

#### Результат тестирования

Бот отправит три ответа от модели с разными температурами:
- **Temperature = 0** (детерминированность) - стабильные, предсказуемые ответы
- **Temperature = 0.7** (сбалансированность) - универсальный режим
- **Temperature = 1.0** (креативность) - оригинальные, разнообразные ответы

Затем бот проведет автоматический анализ и предоставит:
- Сравнение схожести между ответами
- Оценку вариативности результатов
- Рекомендации по выбору температуры для вашей задачи

#### Когда использовать разные температуры

**Temperature = 0 (Детерминированность)**
- Точные ответы на фактические вопросы
- Классификация и категоризация
- Извлечение данных из текста
- Переводы
- Технические инструкции

**Temperature = 0.7 (Сбалансированность)**
- Диалоги и общение
- Ответы на общие вопросы
- Объяснения и обучение
- Повседневные задачи
- Рекомендуется по умолчанию

**Temperature = 1.0 (Креативность)**
- Генерация идей и brainstorming
- Creative writing (рассказы, стихи)
- Нестандартные решения задач
- Маркетинговые слоганы и названия
- Художественные описания

## Технические детали

### Компоненты

1. **YandexGPTClient** ([bot.py:41](bot.py#L41))
   - Отправка запросов к Yandex GPT API
   - Поддержка динамических системных промптов
   - Обработка ошибок и таймаутов

2. **FormatManager** ([format_manager.py:16](format_manager.py#L16))
   - Парсинг JSON/XML с fallback стратегией
   - Валидация структурированных данных
   - Форматирование для разных режимов вывода

3. **TelegramBot** ([bot.py:130](bot.py#L130))
   - Обработка команд и сообщений
   - Хранение состояний пользователей
   - Выбор системного промпта по режиму

4. **TemperatureTester** ([temperature_tester.py:30](temperature_tester.py#L30))
   - Тестирование LLM с разными температурами (0, 0.7, 1.0)
   - Параллельная отправка запросов к API
   - Автоматический анализ и сравнение результатов
   - Генерация рекомендаций по использованию температуры

### Парсинг ответов (3-уровневая стратегия)

**JSON:**
1. Прямой `json.loads()`
2. Извлечение из markdown блока ` ```json...``` `
3. Fallback через regex

**XML:**
1. Прямой `ET.fromstring()`
2. Извлечение из markdown блока ` ```xml...``` `
3. Fallback через regex

### Формат структурированных данных

Все ответы содержат три обязательных поля:
- `datetime` - текущая дата/время в ISO 8601 (2025-11-05T14:30:00)
- `question` - краткая тема вопроса пользователя
- `answer` - полный текстовый ответ от AI

## Устранение неполадок

### Ошибка парсинга
Если бот показывает ошибку парсинга:
- Проверьте логи в консоли
- Yandex GPT иногда возвращает ответы с markdown
- Fallback парсинг должен обрабатывать большинство случаев

### Режим не сохраняется
- Режимы хранятся в памяти
- После перезапуска бота все пользователи вернутся к режиму TEXT

### HTTP ошибки Yandex GPT
- **401**: Проверьте `YANDEX_API_KEY` и права сервисного аккаунта
- **400**: Проверьте `YANDEX_FOLDER_ID`
- **429**: Превышен лимит запросов, подождите

## Логирование

- Переключение режимов пользователей
- Запросы к Yandex GPT API

- Все ошибки и предупреждения

Для отладки измените уровень на DEBUG:

## Безопасность

1. **Хранение в памяти** - состояния пользователей теряются при перезапуске
2. **Без контекста** - каждое сообщение обрабатывается независимо
3. **Лимиты API** - зависят от тарифного плана Yandex Cloud
