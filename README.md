# Telegram Bot с Yandex GPT - Генератор Анекдотов

Telegram-бот с поддержкой различных режимов работы, включая специализированный режим **Joker** для генерации анекдотов категории Б.

## Возможности

- **Четыре режима работы:**
  - TEXT - красивое форматирование с иконками (по умолчанию)
  - JSON - структурированный вывод в JSON формате
  - XML - структурированный вывод в XML формате
  - **JOKER - интерактивный генератор анекдотов категории Б**
- **Режим Joker (новинка!):**
  - Интерактивный сбор информации о персонажах, ситуации и месте действия
  - Контекстная беседа с историей сообщений
  - Автоматическая генерация анекдота после 3-5 релевантных сообщений
  - Вежливый возврат к теме при отклонении пользователя
  - Отслеживание прогресса сбора информации
- Динамическое переключение между режимами для каждого пользователя
- Парсинг ответов с 3-уровневой стратегией fallback
- Валидация структурированных данных
- Полное логирование и обработка ошибок

## Требования

- Python 3.10 или выше
- Telegram Bot Token (от [@BotFather](https://t.me/BotFather))
- Yandex Cloud API Key с доступом к Yandex GPT

## Быстрый старт

### 1. Установите зависимости

```bash
pip install -r requirements.txt
```

### 2. Настройте переменные окружения

Создайте файл `.env`:

```env
TELEGRAM_TOKEN=ваш_telegram_bot_token
YANDEX_API_KEY=ваш_yandex_api_key
YANDEX_FOLDER_ID=ваш_yandex_folder_id
```

### 3. Запустите бота

```bash
python bot.py
```

### 4. Протестируйте в Telegram

```
/start          - Начать работу с ботом
/help           - Справка по командам
/text           - Переключить на текстовый режим (по умолчанию)
/json           - Переключить на JSON режим
/xml            - Переключить на XML режим
/joker          - Переключить на режим генератора анекдотов
/newjoke        - Начать создание нового анекдота (в режиме Joker)
/status         - Показать текущий режим
```

**Особенности режима Joker:**
- Бот запоминает контекст разговора
- Отслеживает релевантность сообщений (говорите ли вы об анекдоте или отвлеклись)
- При попытке обсудить другие темы — вежливо возвращает к созданию анекдота
- После генерации анекдота контекст автоматически сбрасывается
- Используйте `/newjoke` чтобы начать создание нового анекдота в любой момент

## Технические детали

### Компоненты

1. **JokeContext** ([bot.py:41](bot.py#L41))
   - Хранение контекста диалога для генерации анекдотов
   - Отслеживание релевантных сообщений (счётчик)
   - Извлечение информации о персонажах, ситуации и месте
   - История сообщений для контекста беседы
   - Автоматический сброс после генерации анекдота

2. **YandexGPTClient** ([bot.py:97](bot.py#L97))
   - Отправка запросов к Yandex GPT API
   - Поддержка динамических системных промптов
   - Поддержка истории сообщений для контекстной беседы
   - Обработка ошибок и таймаутов

3. **FormatManager** ([format_manager.py:16](format_manager.py#L16))
   - Парсинг JSON/XML с fallback стратегией
   - Валидация структурированных данных
   - Форматирование для разных режимов вывода
   - Специальное форматирование для режима Joker

4. **TelegramBot** ([bot.py:197](bot.py#L197))
   - Обработка команд и сообщений
   - Хранение состояний пользователей (режимы)
   - Хранение контекстов для режима Joker
   - Выбор системного промпта по режиму
   - Управление историей сообщений

### Парсинг ответов (4-уровневая стратегия с автоисправлением)

**JSON:**
1. Прямой `json.loads()`
2. Извлечение из markdown блока ` ```json...``` ` или ` ```...``` ` (гибкий regex, поддерживает варианты с/без переноса строки)
   - При ошибке парсинга: автоматическое исправление незакрытых структур (добавление недостающих `}` и `]`)
3. Fallback: поиск JSON через regex `{...}` с валидацией полей
4. Fallback: извлечение полей через regex для старого формата

**XML:**
1. Прямой `ET.fromstring()`
2. Извлечение из markdown блока ` ```xml...``` ` (гибкий regex)
3. Fallback через regex для извлечения полей

### Формат структурированных данных

**Обычные режимы (TEXT, JSON, XML):**
Все ответы содержат три обязательных поля:
- `datetime` - текущая дата/время в ISO 8601 (2025-11-05T14:30:00)
- `question` - краткая тема вопроса пользователя
- `answer` - полный текстовый ответ от AI

**Режим Joker:**
Ответы в режиме Joker содержат расширенную структуру:
- `datetime` - текущая дата/время в ISO 8601
- `message_type` - тип сообщения: `collecting` (сбор информации), `redirecting` (возврат к теме), `joke` (анекдот готов)
- `relevant_count` - количество релевантных сообщений (0-5)
- `collected_info` - объект с собранной информацией:
  - `characters` - описание персонажей
  - `situation` - описание ситуации
  - `location` - описание места действия
- `answer` - текст ответа пользователю

**Логика работы режима Joker:**
1. Пользователь отправляет сообщение о персонажах, ситуации или месте
2. Yandex GPT анализирует сообщение и определяет его релевантность теме анекдота
3. Если сообщение релевантно — увеличивается счётчик `relevant_count` и обновляется `collected_info`
4. Если пользователь отвлёкся — бот возвращает его к теме (`message_type: redirecting`)
5. После 3-5 релевантных сообщений бот генерирует анекдот (`message_type: joke`)
6. После генерации контекст автоматически сбрасывается для нового анекдота

## Устранение неполадок

### Ошибка парсинга
Если бот показывает ошибку парсинга:
- Проверьте логи в консоли
- Yandex GPT иногда возвращает ответы с markdown (` ``` ` или ` ```json `)
- Улучшенный парсер поддерживает markdown блоки с/без переноса строки после открывающих кавычек
- Автоматическое исправление незакрытых JSON структур (отсутствующие `}` или `]`)
- Fallback парсинг обрабатывает JSON с `null` значениями в режиме Joker

### Режим не сохраняется
- Режимы хранятся в памяти
- После перезапуска бота все пользователи вернутся к режиму TEXT

### HTTP ошибки Yandex GPT
- **401**: Проверьте `YANDEX_API_KEY` и права сервисного аккаунта
- **400**: Проверьте `YANDEX_FOLDER_ID`
- **429**: Превышен лимит запросов, подождите

## Известные ограничения

1. **Хранение в памяти** - состояния пользователей и контексты теряются при перезапуске
2. **Контекст только в режиме Joker** - обычные режимы (TEXT, JSON, XML) обрабатывают каждое сообщение независимо
3. **Лимиты API** - зависят от тарифного плана Yandex Cloud
4. **История ограничена** - в режиме Joker хранятся только последние 10 сообщений
