# Telegram Bot с Yandex GPT

Telegram-бот с поддержкой структурированных ответов от Yandex GPT в форматах JSON, XML и красивом текстовом представлении.

## Возможности

- **Три режима вывода:**
  - TEXT - красивое форматирование с иконками (по умолчанию)
  - JSON - структурированный вывод в JSON формате
  - XML - структурированный вывод в XML формате
- **Сравнение стратегий рассуждения:**
  - 4 различных подхода к решению одной логической задачи
  - Встроенная тестовая задача или пользовательская задача на выбор
  - Интерактивное меню выбора типа задачи
  - Демонстрация влияния формата промпта на качество ответа
  - Детальный сравнительный анализ результатов
- Динамическое переключение между режимами для каждого пользователя
- Парсинг ответов с 3-уровневой стратегией fallback
- Валидация структурированных данных
- Полное логирование и обработка ошибок

## Требования

- Python 3.10 или выше
- Telegram Bot Token (от [@BotFather](https://t.me/BotFather))
- Yandex Cloud API Key с доступом к Yandex GPT

## Быстрый старт

### 1. Установите зависимости

```bash
pip install -r requirements.txt
```

### 2. Настройте переменные окружения

Создайте файл `.env`:

```env
TELEGRAM_TOKEN=ваш_telegram_bot_token
YANDEX_API_KEY=ваш_yandex_api_key
YANDEX_FOLDER_ID=ваш_yandex_folder_id
```

### 3. Запустите бота

```bash
python bot.py
```

### 4. Протестируйте в Telegram

```
/start              - Начать работу с ботом
/help               - Справка по командам
/text               - Переключить на текстовый режим (по умолчанию)
/json               - Переключить на JSON режим
/xml                - Переключить на XML режим
/status             - Показать текущий режим
/compare_reasoning  - Сравнить 4 стратегии рассуждения
/cancel             - Отменить ввод пользовательской задачи
```

## Сравнение стратегий рассуждения

### Обзор

Команда `/compare_reasoning` запускает демонстрацию 4 различных подходов к решению одной и той же логической задачи. Это позволяет наглядно увидеть, как формат промпта влияет на качество, структуру и полноту ответа модели Yandex GPT.

### Тестовая задача

**Задача о переправе через реку:**
Фермеру нужно переправиться через реку вместе с волком, козой и капустой. Лодка вмещает только фермера и одного пассажира. Нельзя оставлять волка с козой без присмотра (волк съест козу) и козу с капустой (коза съест капусту). Как переправить всех?

### Четыре подхода

#### Подход 1: Прямой ответ
- **Описание:** Модель получает только задачу без дополнительных инструкций
- **Промпт:** Минимальный - только текст задачи и просьба предоставить решение
- **Цель:** Базовый уровень - как модель справляется без подсказок

#### Подход 2: Пошаговое решение
- **Описание:** Явная инструкция модели решать задачу пошагово
- **Промпт:** "Решай задачу пошагово. Распиши каждый шаг решения подробно"
- **Цель:** Проверить, улучшается ли качество при явном указании на структурированное мышление

#### Подход 3: Мета-промптинг
- **Описание:** Модель сначала создает оптимальный промпт для решения, затем использует его
- **Промпт:** Двухэтапный процесс:
  1. "Создай оптимальный промпт для решения этой задачи"
  2. Использование сгенерированного промпта для решения
- **Цель:** Проверить, может ли модель самостоятельно оптимизировать подход к задаче

#### Подход 4: Группа экспертов
- **Описание:** Создание виртуальной команды из 3 экспертов разных специализаций
- **Эксперты:**
  - Логик - формальная логика и алгоритмы
  - Практик - простота и практичность реализации
  - Системный аналитик - системный анализ и оптимизация
  - Модератор - синтез мнений экспертов
- **Цель:** Проверить эффект "коллективного разума" для решения задачи

### Формат результатов

Отчет включает:
1. **Описание тестовой задачи**
2. **Результаты каждого подхода:**
   - Описание подхода
   - Время выполнения
   - Полный ответ модели
3. **Сравнительная статистика:**
   - Успешность выполнения
   - Общее время
   - Среднее время на подход

### Выводы из тестирования

После выполнения команды вы сможете увидеть:

- **Различия в структуре ответов:** Пошаговый подход обычно дает более детализированные решения
- **Полнота решений:** Подход с экспертами часто предлагает альтернативные варианты
- **Время выполнения:** Мета-промптинг требует двух запросов и занимает больше времени
- **Качество решения:** Все подходы должны прийти к правильному решению, но по-разному его презентуют

### Рекомендации по выбору подхода

- **Прямой ответ:** Для простых, хорошо определенных задач
- **Пошаговое решение:** Для сложных задач, требующих детализации
- **Мета-промптинг:** Для нестандартных задач, где оптимальный подход неочевиден
- **Группа экспертов:** Для задач, требующих взгляда с разных точек зрения

## Технические детали

### Компоненты

1. **YandexGPTClient** ([bot.py:41](bot.py#L41))
   - Отправка запросов к Yandex GPT API
   - Поддержка динамических системных промптов
   - Обработка ошибок и таймаутов

2. **FormatManager** ([format_manager.py:16](format_manager.py#L16))
   - Парсинг JSON/XML с fallback стратегией
   - Валидация структурированных данных
   - Форматирование для разных режимов вывода

3. **TelegramBot** ([bot.py:128](bot.py#L128))
   - Обработка команд и сообщений
   - Хранение состояний пользователей
   - Выбор системного промпта по режиму

4. **ReasoningComparator** ([reasoning_comparator.py:35](reasoning_comparator.py#L35))
   - Выполнение 4 подходов к решению задачи
   - Сбор метрик времени выполнения
   - Форматирование сравнительного отчета
   - Обработка ошибок при выполнении подходов

### Парсинг ответов (3-уровневая стратегия)

**JSON:**
1. Прямой `json.loads()`
2. Извлечение из markdown блока ` ```json...``` `
3. Fallback через regex

**XML:**
1. Прямой `ET.fromstring()`
2. Извлечение из markdown блока ` ```xml...``` `
3. Fallback через regex

### Формат структурированных данных

Все ответы содержат три обязательных поля:
- `datetime` - текущая дата/время в ISO 8601 (2025-11-05T14:30:00)
- `question` - краткая тема вопроса пользователя
- `answer` - полный текстовый ответ от AI

## Устранение неполадок

### Ошибка парсинга
Если бот показывает ошибку парсинга:
- Проверьте логи в консоли
- Yandex GPT иногда возвращает ответы с markdown
- Fallback парсинг должен обрабатывать большинство случаев

### Режим не сохраняется
- Режимы хранятся в памяти
- После перезапуска бота все пользователи вернутся к режиму TEXT

### HTTP ошибки Yandex GPT
- **401**: Проверьте `YANDEX_API_KEY` и права сервисного аккаунта
- **400**: Проверьте `YANDEX_FOLDER_ID`
- **429**: Превышен лимит запросов, подождите
