# Telegram Bot с Yandex GPT

Простой Telegram-бот, который использует Yandex GPT для ответов на вопросы пользователей. Учебный проект без использования внешних инструментов (tools).

## Возможности

- Ответы на текстовые сообщения через Yandex GPT API
- Обработка команд `/start` и `/help`
- Проверка длины сообщений (лимит 2000 символов)
- Обработка ошибок и таймаутов
- Подробное логирование

## Требования

- Python 3.10 или выше
- Telegram Bot Token (от [@BotFather](https://t.me/BotFather))
- Yandex Cloud API Key с доступом к Yandex GPT

## Установка и настройка

### 1. Клонируйте репозиторий или скопируйте файлы

```bash
git clone <your-repo-url>
cd ai_challenge_4_telegram
```

### 2. Установите зависимости

```bash
pip install -r requirements.txt
```

Или установите вручную:

```bash
pip install python-telegram-bot==20.7 httpx==0.25.2 python-dotenv==1.0.0
```

### 3. Получите необходимые ключи

#### Telegram Bot Token:
1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot` и следуйте инструкциям
3. Скопируйте полученный токен

#### Yandex Cloud API Key:
1. Зарегистрируйтесь в [Yandex Cloud](https://cloud.yandex.ru/)
2. Создайте каталог (folder) или используйте существующий
3. Создайте сервисный аккаунт с ролью `ai.languageModels.user`
4. Создайте API-ключ для сервисного аккаунта
5. Скопируйте API-ключ и ID каталога

### 4. Настройте переменные окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Откройте `.env` и заполните значения:

```env
TELEGRAM_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
YANDEX_API_KEY=AQVNxxxxxxxxxxxxxxxxxxxxxxxxx
YANDEX_FOLDER_ID=b1gxxxxxxxxxxxx
```

**Альтернатива:** Экспортируйте переменные в терминале:

```bash
export TELEGRAM_TOKEN="ваш_токен"
export YANDEX_API_KEY="ваш_api_ключ"
export YANDEX_FOLDER_ID="ваш_folder_id"
```

### 5. Запустите бота

```bash
python bot.py
```

Или сделайте файл исполняемым:

```bash
chmod +x bot.py
./bot.py
```

## Техническая информация

### Архитектура

Бот состоит из трёх основных компонентов:

1. **YandexGPTClient** - класс для работы с Yandex GPT API
   - Формирует HTTP-запросы
   - Обрабатывает ответы
   - Управляет ошибками и таймаутами

2. **TelegramBot** - основной класс бота
   - Регистрирует обработчики команд
   - Обрабатывает сообщения пользователей
   - Валидирует длину сообщений

3. **main()** - точка входа
   - Загружает переменные окружения
   - Валидирует конфигурацию
   - Запускает бота

### Yandex GPT API

**Endpoint:**
```
POST https://llm.api.cloud.yandex.net/foundationModels/v1/completion
```

**Headers:**
```json
{
  "Authorization": "Bearer <YANDEX_API_KEY>",
  "Content-Type": "application/json"
}
```

**Request Body:**
```json
{
  "modelUri": "gpt://<YANDEX_FOLDER_ID>/yandexgpt-lite",
  "completionOptions": {
    "stream": false,
    "temperature": 0.6,
    "maxTokens": 2000
  },
  "messages": [
    {
      "role": "system",
      "text": "Системный промпт..."
    },
    {
      "role": "user",
      "text": "Сообщение пользователя"
    }
  ]
}
```

**Response Structure:**
```json
{
  "result": {
    "alternatives": [
      {
        "message": {
          "role": "assistant",
          "text": "Ответ от GPT"
        },
        "status": "ALTERNATIVE_STATUS_FINAL"
      }
    ]
  }
}
```

## Безопасность

- Никогда не коммитьте файл `.env` в репозиторий
- API-ключи не выводятся в логи
- Используйте `.gitignore` для исключения `.env`:

```bash
echo ".env" >> .gitignore
```

## Устранение неполадок

### Ошибка: "TELEGRAM_TOKEN не задан"
- Убедитесь, что создан файл `.env` с правильными значениями
- Или экспортируйте переменные в терминале

### Ошибка: "HTTP ошибка при запросе к Yandex GPT: 401"
- Проверьте правильность `YANDEX_API_KEY`
- Убедитесь, что сервисный аккаунт имеет роль `ai.languageModels.user`

### Ошибка: "HTTP ошибка при запросе к Yandex GPT: 400"
- Проверьте правильность `YANDEX_FOLDER_ID`
- Убедитесь, что у каталога есть доступ к Yandex GPT

### Бот не отвечает на сообщения
- Проверьте логи в консоли
- Убедитесь, что бот запущен и не выдал ошибок при старте
- Проверьте интернет-соединение
