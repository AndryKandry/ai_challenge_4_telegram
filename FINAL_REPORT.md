## 🔧 Техническая архитектура

### Поток данных

```
Пользователь (Telegram)
    ↓
DeepSeek Provider
    ↓
RAG Manager
    ├─→ Semantic Search (найти документы)
    ├─→ Reranking (улучшить сортировку)
    ├─→ Citation Enrichment (добавить метаданные)
    └─→ MCPLinkGenerator (создать ссылки)
    ↓
Форматирование ответа
    ├─→ Текст с цитатами [1], [2]
    └─→ Список источников с MCP ссылками
    ↓
Отправка в Telegram
```

### Формат MCP URI

```
mcp://filesystem/{url_encoded_path}#lines={start}-{end}

Пример:
mcp://filesystem/%2Frag_docs%2Fdocumentation%2Fguide.md#lines=15-25
```

### Компоненты

1. **MCPLinkGenerator** (`src/integrations/mcp_link_generator.py`)
   - Генерация MCP URI
   - Форматирование источников
   - Фильтрация файлов

2. **RAG Manager** (`src/rag_integration.py`)
   - Поиск документов
   - Цитирование источников
   - Интеграция с MCP

3. **MCP Filesystem Server** (`mcp_server/filesystem.py`)
   - Чтение файлов
   - Навигация по директориям
   - API для работы с файлами

4. **DeepSeek Provider** (`providers/deepseek_provider.py`)
   - Генерация ответов
   - Интеграция с RAG
   - Добавление цитат

- Минимальный overhead
- Кэширование RAG
- Быстрая генерация ссылок

### Ограничения

⚠️ **Telegram**
- mcp:// ссылки не кликабельны нативно
- Требуется MCP-совместимый клиент

⚠️ **Форматы**
- Только TXT и MD
- PDF, DOCX не поддерживаются

⚠️ **Номера строк**
- Аппроксимация (~50 символов/строка)
- Можно улучшить при индексации
