# 🚀 Быстрый старт

## Запуск системы

### Вариант 1: Автоматический запуск (рекомендуется)

Запустите оба компонента одной командой:

```bash
./start.sh
```

Скрипт автоматически:
- ✅ Запустит Weather MCP сервер на http://127.0.0.1:8000/sse
- ✅ Запустит Telegram бота
- ✅ Покажет статус обоих процессов
- ✅ Остановит оба процесса при нажатии Ctrl+C

### Вариант 2: Ручной запуск в двух терминалах

**Терминал 1 - Weather MCP сервер:**
```bash
.venv/bin/python mcp_server/weather.py
```

Вы должны увидеть:
```
╭──────────────────────────────────────────╮
│          FastMCP 2.13.1                  │
│   🖥  Server name: weather                │
│   📦 Transport:   SSE                     │
│   🔗 Server URL:  http://127.0.0.1:8000/sse│
╰──────────────────────────────────────────╯
```

**Терминал 2 - Telegram бот:**
```bash
.venv/bin/python bot.py
```

## Использование в Telegram

После запуска обоих компонентов:

1. Найдите вашего бота в Telegram
2. Отправьте `/start` для начала
3. Используйте `/mcp_tools` для просмотра доступных Weather MCP инструментов

### Доступные команды бота

- `/start` - Начать диалог с ботом
- `/help` - Справка по использованию
- `/mcp_tools` - Список доступных MCP инструментов
- `/status` - Статус системы

### Доступные Weather MCP инструменты

1. **get_alerts** - Получить погодные предупреждения для штата США
   - Параметр: `state` (код штата, например: CA, NY, TX)

2. **get_forecast** - Получить прогноз погоды для координат
   - Параметры: `latitude`, `longitude`

## Проверка работы

### Проверка Weather MCP сервера

Откройте в браузере: http://localhost:8000/sse

Должен начаться SSE stream (браузер будет показывать загрузку).

### Проверка подключения

В боте выполните команду `/mcp_tools`. Вы должны увидеть список из 2 доступных инструментов.

## Остановка системы

### При использовании start.sh

Нажмите `Ctrl+C` в терминале, где запущен скрипт.

### При ручном запуске

Нажмите `Ctrl+C` в каждом из двух терминалов.

## Решение проблем

### ✅ "TimeoutError: MCP session initialization timeout" (ИСПРАВЛЕНО 18.11.2025)

**Статус:** Проблема полностью решена в последней версии `mcp_client.py`.

**Что было:** Клиент зависал на 30 секунд при попытке подключения к серверу.

**Причина:** `ClientSession` не входил в контекст, поэтому `_receive_loop` не запускался.

**Решение:** Добавлены вызовы `__aenter__()` и `__aexit__()` для ClientSession.

**Результат:** Время подключения улучшилось с 30+ секунд до 0.14 секунды.

Подробнее: `docs/FIX_SSE_CONNECTION_ISSUE.md`

### "Команда /mcp_tools зависает"

**Причина:** Weather MCP сервер не запущен.

**Решение:** Убедитесь, что сервер запущен в отдельном терминале или используйте `./start.sh`.

### "Port 8000 already in use"

**Причина:** Порт 8000 уже занят другим процессом.

**Решение:**
```bash
# Найти процесс на порту 8000
lsof -i :8000

# Остановить процесс (замените PID на найденный)
kill <PID>
```

### "Connection refused to localhost:8000"

**Причина:** Сервер не запущен или еще не готов.

**Решение:**
1. Запустите сервер: `.venv/bin/python mcp_server/weather.py`
2. Подождите 2-3 секунды до полной инициализации
3. Попробуйте снова

## Логи и отладка

### Включение DEBUG логов

В начале `bot.py` измените уровень логирования:

```python
logging.basicConfig(
    level=logging.DEBUG,  # Было: INFO
    format="%(asctime)s - %(name)s - %(levelname)s - %(message)s"
)
```

Это покажет подробную информацию о:
- MCP соединениях
- HTTP запросах
- SSE событиях
- Ошибках инициализации
