# Настройка Telegram интеграции

## Проблема

При первом запуске MCP сервера `telegram_assistant.py` работа блокируется, потому что Pyrogram требует интерактивную авторизацию:

```
Enter phone number or bot token:
```

Это блокирует создание первоначальной сводки и весь функционал работы с Telegram чатами.

## Решение: Предварительная авторизация

Перед первым использованием telegram_assistant нужно один раз выполнить авторизацию.

### Шаг 1: Получите Telegram API credentials

1. Перейдите на https://my.telegram.org/apps
2. Войдите со своим номером телефона
3. Создайте приложение (если ещё нет)
4. Скопируйте:
   - **api_id** (числовой ID)
   - **api_hash** (строка из букв и цифр)

### Шаг 2: Добавьте credentials в .env

Откройте файл `.env` и добавьте:

```env
TELEGRAM_API_ID=your_api_id_here
TELEGRAM_API_HASH=your_api_hash_here
```

**Пример:**
```env
TELEGRAM_API_ID=12345678
TELEGRAM_API_HASH=abcdef1234567890abcdef1234567890
```

### Шаг 3: Запустите скрипт авторизации

```bash
python setup_telegram_session.py
```

Скрипт запросит:

1. **Номер телефона** (в международном формате)
   ```
   Пример: +79991234567
   ```

2. **Код подтверждения** (из Telegram)
   ```
   Telegram отправит вам код в сообщении
   Введите его (например: 12345)
   ```

3. **Пароль 2FA** (если включена двухфакторная аутентификация)
   ```
   Введите ваш Cloud Password
   ```

### Шаг 4: Проверьте успешность

После успешной авторизации вы увидите:

```
✅ АВТОРИЗАЦИЯ УСПЕШНА!

Вы вошли как: Ваше Имя
Username: @your_username
ID: 123456789

Session файл сохранён: data/telegram_assistant_mcp.session
```

Файл `data/telegram_assistant_mcp.session` будет создан и **больше не потребуется интерактивный ввод**.

### Шаг 5: Запустите серверы

Теперь можете запускать MCP сервер и бота:

```bash
# В первом терминале
python mcp_server/telegram_assistant.py

# Во втором терминале
python bot.py
```

Всё должно работать автоматически!

## Устранение проблем

### Ошибка: "TELEGRAM_API_ID или TELEGRAM_API_HASH не найдены"

Проверьте файл `.env`:
- Убедитесь, что переменные добавлены без лишних пробелов
- Убедитесь, что файл сохранён

### Ошибка: "The phone number is invalid"

- Используйте международный формат: `+79991234567`
- Не используйте пробелы или тире

### Ошибка: "The password you entered is incorrect"

- Проверьте правильность Cloud Password
- Попробуйте сбросить пароль в настройках Telegram

### Session файл повреждён

Удалите старый session файл и повторите авторизацию:

```bash
rm data/telegram_assistant_mcp.session
python setup_telegram_session.py
```

## Важно

- ⚠️ **Не делитесь session файлом** - это даёт полный доступ к вашему Telegram аккаунту
- ⚠️ Session файл добавлен в `.gitignore` - не коммитьте его в git
- ✅ Авторизация нужна **только один раз**
- ✅ Session файл работает бессрочно (пока вы не выйдете из всех устройств в Telegram)

## Безопасность

Session файл содержит токен доступа к вашему Telegram аккаунту. Защитите его:

```bash
# Убедитесь, что data/ в .gitignore
echo "data/" >> .gitignore

# Ограничьте права доступа (только для вас)
chmod 600 data/telegram_assistant_mcp.session
```
