# Команды пользователя для работы с токенами

## Обзор

Этот документ описывает все команды, доступные пользователям для работы с системой подсчета токенов.

## Команды

### `/tokens` - Статистика последнего запроса

Показывает детальную информацию о последнем запросе пользователя.

**Использование:**
```
/tokens
```

**Пример ответа:**
```
📊 Статистика последнего запроса:

Ваш запрос: 45 токенов
Ответ бота: 320 токенов
Всего: 365 токенов

Лимит модели: 8,192 токенов
Использовано: 4.5% от лимита ✅

💡 Команды:
/tokens_stats - общая статистика
/token_mode off - отключить показ токенов
```

**Когда использовать:**
- Когда нужна детальная информация о последнем запросе
- Для проверки, сколько токенов занял конкретный вопрос
- Для понимания, насколько близко к лимиту

---

### `/tokens_stats` - Общая статистика

Показывает агрегированную статистику использования токенов за сессию и день.

**Использование:**
```
/tokens_stats
```

**Пример ответа:**
```
📈 Ваша статистика использования:

За эту сессию:
├─ Запросов: 12
├─ Всего токенов: 5,430
└─ Средний запрос: 452 токена

За сегодня:
├─ Запросов: 28
├─ Всего токенов: 12,450
└─ Средний запрос: 445 токенов

✅ Отличная работа! Все запросы в пределах лимита.
```

**Когда использовать:**
- Для отслеживания общего использования
- Для анализа своих паттернов запросов
- Для планирования оптимизации запросов

---

### `/token_mode` - Управление отображением

Включает или выключает автоматическое отображение токенов после каждого ответа.

**Использование:**
```
/token_mode on   # Включить автоматический показ
/token_mode off  # Выключить автоматический показ
/token_mode      # Переключить текущее состояние
```

**Пример ответа (включение):**
```
✅ Автоматический показ токенов включён
Теперь после каждого ответа вы будете видеть статистику использования.

Отключить: /token_mode off
```

**Пример ответа (выключение):**
```
ℹ️ Автоматический показ токенов отключён
Вы по-прежнему можете просматривать статистику командами:
/tokens - последний запрос
/tokens_stats - общая статистика

Включить обратно: /token_mode on
```

**Когда использовать:**
- Когда статистика токенов отвлекает
- Когда нужен более чистый интерфейс
- Для временного отключения перед демонстрацией

---

### `/token_settings` - Настройки отображения

Открывает меню с выбором режима отображения токенов.

**Использование:**
```
/token_settings
```

**Пример ответа:**
```
⚙️ Настройки отображения токенов:

Выберите режим:
1️⃣ Скрытый - не показывать токены
2️⃣ Компактный - краткая статистика
3️⃣ Подробный - полная информация ✓
4️⃣ Только предупреждения - показывать при >80% лимита

Отправьте номер режима (1-4) или используйте:
/token_mode on - включить показ
/token_mode off - отключить показ
```

**Режимы отображения:**

#### 1. Скрытый (Hidden)
Токены вообще не отображаются. Можно просмотреть только через `/tokens`.

#### 2. Компактный (Compact)
Краткая однострочная статистика:
```
💬 Токены: запрос 45 | ответ 180 | всего 225 ✅
```

#### 3. Подробный (Detailed) - По умолчанию
Полная статистика с древовидной структурой:
```
📊 Статистика:
├─ Ваш запрос: 45 токенов
├─ Мой ответ: 180 токенов
└─ Всего использовано: 225 токенов

✅ Токены: 225/8192 (3%)
```

#### 4. Только предупреждения (Warnings Only)
Показывается только при использовании >80% лимита:
```
⚠️ Токены: 7000/8192 (85%)
⚠️ Приближаетесь к лимиту модели
```

**Когда использовать:**
- Для настройки персонального опыта
- Когда нужен баланс между информативностью и чистотой интерфейса
- Для адаптации под разные сценарии использования

### `/token_help` - Справка о токенах

Показывает обучающее сообщение о концепции токенов и доступных командах.

**Использование:**
```
/token_help          # Показать справку
/token_help off      # Отключить автоматический показ при первом использовании
```

**Пример ответа:**
```
👋 Привет! Я теперь показываю статистику использования токенов.

🤔 Что такое токены?
Это единицы измерения текста для AI. Примерно:
• 1 токен ≈ 0.75 слова (на русском)
• 100 токенов ≈ 75 слов
• 1000 токенов ≈ 750 слов

📊 Зачем это нужно?
Понимание токенов помогает:
✓ Оптимизировать запросы
✓ Избежать превышения лимитов
✓ Понять, как работает AI

💡 Команды:
/tokens - статистика последнего запроса
/tokens_stats - общая статистика
/token_mode off - отключить показ
/token_settings - настройки

Чтобы скрыть это сообщение в будущем: /token_help off
```

**Когда использовать:**
- При первом знакомстве с системой токенов
- Когда нужно напомнить себе команды
- Для обучения других пользователей

## Автоматические сообщения

### Превышение лимита

При попытке отправить запрос, превышающий лимит модели:

```
🚫 Запрос слишком большой!

📊 Ваш текст: ~9,500 токенов
📏 Максимум модели: 8,192 токенов
❌ Превышение: 1,308 токенов (~16%)

💡 Что можно сделать:
1️⃣ Сократить текст примерно на 16% (~1,400 токенов)
2️⃣ Разбить на 2 части и отправить по очереди
3️⃣ Использовать более краткие формулировки

Попробуйте ещё раз с более коротким текстом!
```

**Действия:**
- Запрос НЕ отправляется в API (экономия квоты)
- Пользователь получает конкретные рекомендации
- Показан точный расчет превышения

### Предупреждение при приближении к лимиту

При использовании 80-90% лимита:

```
⚠️ Токены: 7,500/8,192 (92%)
⚠️ ВНИМАНИЕ! Очень близко к лимиту!

⚠️ Следующий запрос такого размера может не обработаться.
Рекомендую:
• Использовать более короткие запросы
• Разбивать большие тексты на части
• Проверить статистику: /tokens_stats
```

### Обучающее сообщение при первом использовании

Показывается автоматически при первом запросе пользователя (если включено):

```
👋 Привет! Я теперь показываю статистику использования токенов.
[... полный текст справки ...]
```

Можно отключить: `/token_help off`

## Сценарии использования

### Новичок
1. Получите обучающее сообщение при первом запросе
2. Используйте `/token_help` для напоминания команд
3. Начните с подробного режима (по умолчанию)

### Опытный пользователь
1. Переключитесь на компактный режим: `/token_settings` → 2
2. Следите за статистикой через `/tokens_stats`
3. Используйте `/token_mode off` когда токены не нужны

### Разработчик/Тестировщик
1. Режим "Только предупреждения" для фокуса на проблемах
2. Тестирование с примерами из `tests/test_requests_examples.txt`
3. Мониторинг через `/tokens_stats` для анализа

## FAQ

**Q: Могу ли я полностью отключить систему токенов?**
A: Да, используйте `/token_mode off`. Статистика будет собираться, но не отображаться.

**Q: Сохраняются ли мои настройки после перезапуска бота?**
A: Да, все настройки и статистика сохраняются в файлах `user_data/`.

**Q: Сбрасывается ли дневная статистика?**
A: Да, автоматически каждый день в полночь.

**Q: Как точно считаются токены?**
A: Используется примерная оценка: ~1.33 токена на слово для русского языка. Для точного подсчета требуется API токенизации (планируется).

**Q: Что делать при превышении лимита?**
A: Бот покажет конкретные рекомендации. Обычно нужно: 1) Сократить текст, 2) Разбить на части, 3) Упростить формулировки.
