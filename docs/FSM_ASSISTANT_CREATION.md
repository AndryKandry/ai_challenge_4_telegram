# FSM: Интерактивное создание ассистента

**Дата:** 19.11.2025
**Версия:** 1.2.0

---

## 📋 Описание

FSM (Finite State Machine) для создания ассистента с интерактивной настройкой всех параметров через удобный диалог с inline-кнопками.

### Зачем это нужно?

**Проблема:** Команда `/telegram_assistant` создаёт ассистента с фиксированными настройками (интервал = 1 час, стандартный промпт)

**Решение:** Команда `/create_assistant` запускает интерактивный диалог, где пользователь может:
- Выбрать тип интервала (минуты/часы/дни)
- Задать конкретное значение интервала
- Использовать свой кастомный промпт

---

## 🚀 Использование

### Команда: `/create_assistant`

Запускает интерактивный диалог из 4 шагов:

#### Шаг 1: Указание чата
```
🤖 Создание ассистента для автоматических сводок

Шаг 1/4: Укажите ID или username чата

Примеры:
• @channel_name
• @username
• -1001234567890

Отправьте /cancel для отмены
```

Пользователь вводит текстом, например: `@tech_news`

---

#### Шаг 2: Выбор типа интервала
```
✅ Чат: @tech_news

Шаг 2/4: Выберите тип интервала

Как часто создавать сводки?

[⏱ Минуты] [🕐 Часы]
     [📅 Дни]
```

Пользователь нажимает кнопку, например: **🕐 Часы**

---

#### Шаг 3: Выбор значения интервала
```
Шаг 3/4: Выберите интервал в часах

[1 час] [2 часа] [3 часа]
[6 часов] [12 часов]
[✏️ Ввести своё значение]
```

Варианты кнопок зависят от выбранного типа:

**Для минут:**
- 5, 10, 15, 30, 45 минут
- Ввести своё значение

**Для часов:**
- 1, 2, 3, 6, 12 часов
- Ввести своё значение

**Для дней:**
- 1, 2, 3, 7 дней
- Ввести своё значение

Если пользователь выбирает "Ввести своё значение", бот просит ввести число текстом.

---

#### Шаг 4: Выбор промпта
```
✅ Интервал: каждые 2 часа

Шаг 4/4: Промпт для анализа сообщений

Стандартный промпт фокусируется на:
• Основных темах обсуждения
• Важных решениях и договоренностях
• Проблемах и блокерах

Хотите использовать свой промпт?

[✅ Использовать стандартный]
[✏️ Ввести свой промпт]
```

Если пользователь выбирает "Ввести свой промпт", бот просит ввести текст промпта.

---

#### Шаг 5: Подтверждение
```
📋 Подтверждение создания ассистента

Чат: @tech_news
Интервал: каждые 2 часа
Промпт: стандартный

Создать ассистента?

[✅ Создать] [❌ Отменить]
```

После подтверждения бот создаёт ассистента.

## 🔄 Отмена процесса

В любой момент пользователь может отправить `/cancel` для отмены создания:

```
Пользователь: /cancel
Бот: ❌ Создание ассистента отменено.

     Используйте /create_assistant для повторной попытки.
```

## 🏗 Техническая реализация

### Архитектура

```
bot.py
  ↓
fsm_handlers.py
  ↓
  AssistantCreationFSM (класс)
    ├── start_creation() - Старт FSM
    ├── receive_chat_id() - Получение chat_id
    ├── receive_interval_type() - Выбор типа интервала
    ├── receive_interval_value() - Выбор значения
    ├── receive_custom_interval_value() - Ввод кастомного значения
    ├── receive_prompt_choice() - Выбор промпта
    ├── receive_custom_prompt() - Ввод кастомного промпта
    ├── confirm_creation() - Подтверждение и создание
    └── cancel() - Отмена
```

### Состояния FSM

```python
CHAT_ID = 0          # Ввод chat_id
INTERVAL_TYPE = 1    # Выбор типа интервала
INTERVAL_VALUE = 2   # Выбор/ввод значения
CUSTOM_PROMPT = 3    # Выбор/ввод промпта
CONFIRM = 4          # Подтверждение
```

### ConversationHandler

```python
ConversationHandler(
    entry_points=[
        CommandHandler("create_assistant", fsm.start_creation)
    ],
    states={
        CHAT_ID: [MessageHandler(...)],
        INTERVAL_TYPE: [CallbackQueryHandler(...)],
        INTERVAL_VALUE: [CallbackQueryHandler(...), MessageHandler(...)],
        CUSTOM_PROMPT: [CallbackQueryHandler(...), MessageHandler(...)],
        CONFIRM: [CallbackQueryHandler(...)]
    },
    fallbacks=[
        CommandHandler("cancel", fsm.cancel)
    ]
)
```

### Хранение данных

Данные сохраняются в `context.user_data`:

```python
context.user_data = {
    'chat_id': '@tech_news',
    'chat_name': '@tech_news',
    'interval_type': 'hour',
    'interval_value': 2,
    'custom_prompt': None  # или текст кастомного промпта
}
```

## 📊 Сравнение команд

| Параметр | `/telegram_assistant` | `/create_assistant` |
|----------|----------------------|---------------------|
| **Интерфейс** | Одна команда | Интерактивный диалог (4 шага) |
| **Интервал** | Фиксированный (1 час) | Выбирается пользователем |
| **Промпт** | Стандартный | Стандартный или кастомный |
| **Простота** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |
| **Гибкость** | ⭐ | ⭐⭐⭐⭐⭐ |

### Когда использовать `/telegram_assistant`
- Нужно быстро создать ассистента
- Интервал 1 час подходит
- Стандартный промпт подходит

### Когда использовать `/create_assistant`
- Нужен конкретный интервал (например, 30 минут или 6 часов)
- Нужен кастомный промпт
- Хочется видеть все параметры перед созданием

## 🐛 Troubleshooting

### Проблема: "Команда /create_assistant не работает"

**Решение:**
1. Убедитесь что `fsm_handlers.py` создан
2. Проверьте что Scheduler Manager инициализирован
3. Проверьте логи: `INFO: FSM обработчик создания ассистента зарегистрирован`

### Проблема: "Inline кнопки не отображаются"

**Решение:**
1. Убедитесь что используется `python-telegram-bot>=22.0`
2. Проверьте что callback_data не содержит ошибок

### Проблема: "Бот не реагирует на текстовый ввод"

**Решение:**
- Убедитесь что MessageHandler зарегистрирован для нужного состояния
- Проверьте что не используются фильтры COMMAND для текстовых сообщений
