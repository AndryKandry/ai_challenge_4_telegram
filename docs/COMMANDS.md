# Документация: Команды бота

Полный справочник всех команд Telegram бота с примерами использования.

## Управление LLM моделями

### `/openai` - Переключение на OpenAI GPT

Переключить бота на использование OpenAI GPT (gpt-3.5-turbo).

**Ответ при успехе:**
```
✅ Выбрана модель OpenAI GPT
Теперь я буду использовать OpenAI для генерации ответов.
```

**Ответ при недоступности:**
```
❌ OpenAI провайдер недоступен
OpenAI API ключ не был настроен при запуске бота.
```

---

### `/yandex` - Переключение на Yandex GPT

Переключить бота на использование Yandex GPT (yandexgpt-lite).

**Ответ:**
```
✅ Выбрана модель Yandex GPT
Теперь я буду использовать Yandex для генерации ответов.
```

---

### `/deepseek` - Переключение на DeepSeek

Переключить бота на использование DeepSeek (deepseek-chat).

**Ответ при успехе:**
```
✅ Выбрана модель DeepSeek
Теперь я буду использовать DeepSeek для генерации ответов.
```

---

### `/model` - Показать текущую модель

Показывает информацию о текущей выбранной LLM модели.

**Пример ответа:**
```
🤖 Текущая модель: OpenAI GPT

Модель: gpt-3.5-turbo
Провайдер: OpenAI

Альтернативы:
/yandex - Yandex GPT
/deepseek - DeepSeek
```

---

## Режимы вывода

### `/text` - Текстовый режим
Красивое форматирование с иконками (по умолчанию).

### `/json` - JSON режим
Ответ в формате JSON кода.

### `/xml` - XML режим
Ответ в формате XML кода.

### `/status` - Проверить режим
Показать текущий режим вывода.

---

## Управление сессиями

### `/session_info` - Информация о сессии
Показывает ID сессии, количество сообщений, время начала.

### `/new_session` - Новая сессия
Создаёт новую сессию и очищает контекст.

### `/end_session` - Завершить сессию
Завершает текущую сессию.

---

## Управление памятью

### `/memory_stats` - Статистика
Показывает количество сообщений, фактов, действий.

### `/clear_memory [confirm]` - Очистить историю
Удаляет все сообщения из базы данных.

### `/export_memory [format]` - Экспорт
Экспортирует историю в формате text/json/csv.

---

## Дополнительные команды

### `/start` - Начать работу
Приветственное сообщение с кратким описанием.

### `/help` - Справка
Полная справка по всем командам.

### `/test_temperature [prompt]` - Тест температуры
Сравнивает работу LLM при разных температурах.

### `/mcp_tools` - MCP инструменты
Показывает доступные внешние инструменты (Weather API).

---

## Примеры использования

### Переключение моделей
```
You: /model
Bot: 🤖 Текущая модель: OpenAI GPT

You: /deepseek
Bot: ✅ Выбрана модель DeepSeek

You: Привет!
Bot: [Ответ от DeepSeek]
```

### Управление контекстом
```
You: Привет, меня зовут Иван
Bot: Здравствуйте, Иван!

You: Как меня зовут?
Bot: Вас зовут Иван

You: /new_session
You: Как меня зовут?
Bot: Я не знаю вашего имени
(контекст очищен)
```

### Экспорт истории
```
You: /export_memory json
Bot: [Отправляет файл с историей]
```
