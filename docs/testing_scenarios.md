# Тестовые сценарии для системы подсчета токенов

## Обзор

Этот документ описывает тестовые сценарии для проверки функциональности подсчета токенов.

## Файлы тестов

**`tests/test_requests_examples.txt`** - Содержит примеры запросов разного размера для ручного тестирования.

## Сценарии тестирования

### 1. Короткий запрос (< 100 токенов)

**Цель:** Проверить корректную работу с минимальными запросами.

**Тестовые данные:**
```
"Привет! Как дела?"
"Что такое Python?"
"Расскажи краткий факт о космосе."
```

**Ожидаемый результат:**
- Подсчет: ~5-15 токенов для запроса
- Ответ отображается нормально
- Статистика показывает зеленый индикатор ✅
- Процент использования < 5%

**Проверить:**
- [x] Корректный подсчет токенов
- [x] Отображение статистики (если включено)
- [x] Обновление пользовательской статистики
- [x] Логирование в консоль

---

**Цель:** Проверить работу с запросами среднего размера.

- Подсчет: ~150-300 токенов для запроса

- Индикатор: ✅ (< 50% лимита)

**Проверить:**
- [x] Корректная обработка запроса
- [x] Подсчет токенов ответа
- [x] Статистика за сессию обновляется
- [x] Средний показатель считается правильно

**Проверить:**

- [x] API квота не расходуется

## Тестирование команд

### `/tokens`

**Сценарий:**
1. Отправить запрос
2. Выполнить `/tokens`

**Ожидаемый результат:**
- Показана статистика последнего запроса
- Информация точная и актуальная

### `/tokens_stats`

**Сценарий:**
1. Отправить несколько запросов (например, 5)
2. Выполнить `/tokens_stats`

**Ожидаемый результат:**
- Показана агрегированная статистика
- Количество запросов корректно
- Средний показатель посчитан правильно

### `/token_mode on/off`

**Сценарий:**
1. Выполнить `/token_mode off`
2. Отправить запрос
3. Проверить, что токены не отображаются
4. Выполнить `/token_mode on`
5. Отправить запрос
6. Проверить, что токены отображаются

**Ожидаемый результат:**
- Режим переключается корректно
- Настройки сохраняются

### `/token_settings`

**Сценарий:**
1. Выполнить `/token_settings`
2. Выбрать режим (отправить 1, 2, 3 или 4)
3. Отправить запрос
4. Проверить формат отображения

**Ожидаемый результат:**
- Меню отображается корректно
- Режим применяется после выбора
- Формат соответствует выбранному режиму

### `/token_help`

**Сценарий:**
1. Выполнить `/token_help`

**Ожидаемый результат:**
- Показана полная справка о токенах
- Информация актуальная и понятная

## Тестирование режимов отображения

### Скрытый (Hidden)

**Проверить:**
- Токены не отображаются вообще
- Статистика все еще собирается
- `/tokens` показывает данные

### Компактный (Compact)

**Проверить:**
- Однострочный формат
- Показаны основные цифры
- Индикатор присутствует

### Подробный (Detailed)

**Проверить:**
- Древовидная структура
- Все детали отображены
- Индикатор и процент показаны

### Только предупреждения (Warnings Only)

**Проверить:**
- При < 80%: токены не показываются
- При >= 80%: показано предупреждение
- Формат предупреждения корректный
