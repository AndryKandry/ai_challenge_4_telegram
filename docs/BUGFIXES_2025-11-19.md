## 🐛 Обнаруженные проблемы

### 1. DeepSeek не видит Telegram Assistant MCP tools
**Проблема:** При создании ассистента и первоначальной сводке DeepSeek не может вызвать `get_chat_messages`, хотя инструмент доступен.

**Причина:** DeepSeek Provider поддерживал только один `mcp_client`, а в bot.py пытались добавить несколько клиентов через список `mcp_clients`.

**Исправление:**
- Обновлён `providers/deepseek_provider.py`:
  - Добавлена поддержка списка `mcp_clients` вместо одного `mcp_client`
  - Метод `_get_mcp_tools_definitions()` теперь собирает tools от всех подключенных MCP клиентов
  - Метод `_handle_tool_calls()` ищет нужный MCP клиент для каждого tool
  - Добавлен метод `add_mcp_client()` для добавления клиентов

- Обновлён `bot.py`:
  - Использован метод `add_mcp_client()` для добавления Telegram Assistant MCP

**Файлы:**
- `providers/deepseek_provider.py:33-380`
- `bot.py:280-284`

### 2. Ассистенты не запускаются по расписанию
**Проблема:** В `/list_assistants` все ассистенты показывают "Следующий запуск: -", задачи не выполняются по расписанию.

**Причина:** В `scheduler/manager.py` при добавлении задачи `next_run_time=start_time`, а `start_time=None`, что приводило к немедленному выполнению без планирования будущих запусков.

**Исправление:**
- Обновлён `scheduler/manager.py`, метод `_add_scheduler_job()`:
  - Если `start_time=None`, вычисляется время первого запуска = текущее время + интервал
  - Добавлена логика для всех типов интервалов (minute, hour, day, custom)

**Файлы:**
- `scheduler/manager.py:165-216`

**Пример:** Для ассистента с интервалом "каждый час", первый запуск = сейчас + 1 час

### 3. Отсутствуют команды удаления ассистентов
**Проблема:** Есть только команды остановки (`/stop_assistant`), но нет команд для полного удаления ассистентов из БД.

**Исправление:**

#### 3.1. Добавлены методы в `SchedulerManager`:
- `delete_assistant(user_id, chat_name)` - удаление одного ассистента
- `delete_all_assistants(user_id)` - удаление всех ассистентов пользователя

#### 3.2. Добавлен метод в `Database`:
- `delete_assistant(assistant_id)` - удаляет ассистента и связанные записи из `execution_history`

#### 3.3. Добавлены команды бота:
- `/delete_assistant <chat_name>` - удалить ассистента
- `/delete_all_assistants confirm` - удалить все (с подтверждением)

#### 3.4. Обновлены сообщения:
- `/start` - добавлены новые команды
- `/help` - добавлены новые команды (TODO)

**Файлы:**
- `scheduler/manager.py:406-485`
- `storage/database.py:320-352`
- `bot.py:335-336,1498-1561`

## ✅ Результат

После исправлений:

### 1. MCP Tools работают корректно
DeepSeek теперь имеет доступ к обоим MCP клиентам:
- GitHub MCP: `get_user_repositories`, `get_user_info`, `get_repository_commits`
- Telegram Assistant MCP: `get_chat_messages`, `get_chat_info`, `validate_chat_access`

При создании ассистента первоначальная сводка **успешно получает данные** из чата через `get_chat_messages`.

### 2. Расписание работает
Ассистенты запускаются по расписанию:
- В `/list_assistants` показывается корректное время следующего запуска
- Например: "⏰ Следующий запуск: 22:30 (через 54 мин)"
- Задачи автоматически выполняются каждый час (или по заданному интервалу)

### 3. Удаление ассистентов доступно
Пользователи могут:
- Удалить отдельного ассистента: `/delete_assistant @channel_name`
- Удалить всех ассистентов: `/delete_all_assistants confirm`
- При удалении очищается БД и удаляются задачи из планировщика
