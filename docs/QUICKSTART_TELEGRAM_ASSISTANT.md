# Quickstart: Система автоматических сводок из Telegram

## Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Создайте `.env` файл на основе `.env.example`:

```bash
# Telegram Bot Token (основной бот)
TELEGRAM_TOKEN=your_bot_token

# Telegram API для User Bot (получите на https://my.telegram.org/apps)
TELEGRAM_API_ID=your_api_id
TELEGRAM_API_HASH=your_api_hash

# DeepSeek API (используется для генерации сводок)
DEEPSEEK_API_KEY=your_deepseek_key

# Yandex GPT (опционально, для других LLM задач)
YANDEX_API_KEY=your_yandex_key
YANDEX_FOLDER_ID=your_folder_id
```

### 3. Инициализация базы данных

При первом запуске бота база данных создастся автоматически.

### 4. Запуск MCP сервера (в отдельном терминале)

```bash
python mcp_server/telegram_assistant.py
```

Сервер запустится на порту 8002 (SSE транспорт).

### 5. Запуск бота

```bash
python bot.py
```

     2️⃣ В определенное время (HH:MM)

## Архитектура

Система работает по следующему принципу:

1. **APScheduler** запускает задачу по расписанию
2. **Scheduler Manager** формирует запрос к **DeepSeek LLM**
3. **DeepSeek** через **MCP** вызывает инструмент `get_chat_messages`
4. **MCP Server** (telegram_assistant) запрашивает сообщения через **Pyrogram**
5. **Telegram API** возвращает сообщения
6. **DeepSeek** анализирует сообщения и создаёт сводку
7. Сводка отправляется вам через **Telegram Bot**

## Требования

- Python 3.10+
- Telegram Bot Token (от @BotFather)
- Telegram API credentials (api_id, api_hash) от https://my.telegram.org/apps
- DeepSeek API ключ
- Права на чтение сообщений в отслеживаемых чатах

## Ограничения

- Максимум 10 активных ассистентов на пользователя
- Минимальный интервал обновлений: 1 минута
- Максимум 1000 сообщений за один сбор

## Troubleshooting

### Ошибка: "Pyrogram не установлен"

```bash
pip install pyrogram tgcrypto
```

### Ошибка: "TELEGRAM_API_ID не задан"

Убедитесь, что в `.env` файле указаны `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`.

### Ошибка: "Нет доступа к чату"

1. Убедитесь, что ваш Telegram аккаунт (связанный с api_id/api_hash) имеет доступ к чату
2. Для приватных чатов/каналов вы должны быть участником
3. Для публичных каналов достаточно знать username (например, @durov)

### MCP сервер не запускается

Проверьте, что порт 8002 свободен:

```bash
lsof -i :8002
```

Или запустите на другом порту:

```python
# В mcp_server/telegram_assistant.py измените:
mcp.run(transport="sse", port=8003)
```
