## 🚀 Быстрый тест

### Шаг 1: Перезапустите систему

```bash
# Терминал 1: MCP сервер
python mcp_server/telegram_assistant.py

# Терминал 2: Бот
python bot.py
```

### Шаг 2: Создайте ассистента

В Telegram боте:
```
/telegram_assistant @your_test_channel
```

**Ожидаемый результат:**
1. Сообщение "✅ Ассистент создан"
2. Через 5-10 секунд: "⏳ Создаю первоначальную сводку..."
3. Через 10-30 секунд: **Первоначальная сводка с реальными данными из чата** (не ошибка!)

### Шаг 3: Проверьте расписание

```
/list_assistants
```

**Ожидаемый результат:**
```
📋 Ваши ассистенты (1, активных: 1):

1. ✅ @your_test_channel
   📊 каждый час
   ⏰ Следующий запуск: 22:30 (через 54 мин)  ← Должно показать время!
   🆔 ID: abc12345
```

### Шаг 4: Проверьте удаление

```
/delete_assistant @your_test_channel
```

**Ожидаемый результат:**
```
✅ Ассистент для чата '@your_test_channel' удалён
```

Проверка:
```
/list_assistants
```

Должно показать: "📭 У вас пока нет ассистентов"

## ✅ Чек-лист проверки

### 1. MCP Tools работают
- [ ] Первоначальная сводка **не содержит** ошибку "К сожалению, у меня сейчас нет доступа к инструменту"
- [ ] Сводка **содержит реальные данные** из чата (темы, сообщения, участники)
- [ ] В логах bot.py есть строка: `INFO: MCP Tools доступны: 6 инструментов` (3 GitHub + 3 Telegram Assistant)

### 2. Расписание работает
- [ ] `/list_assistants` показывает **конкретное время** следующего запуска, например "22:30 (через 54 мин)"
- [ ] НЕ показывает `-` вместо времени
- [ ] Через указанный интервал (час) приходит автоматическая сводка

### 3. Удаление работает
- [ ] `/delete_assistant <chat>` удаляет ассистента
- [ ] После удаления `/list_assistants` не показывает удалённого ассистента
- [ ] `/delete_all_assistants confirm` удаляет всех ассистентов
- [ ] Команда `/delete_all_assistants` без `confirm` показывает предупреждение

## 🐛 Если что-то не работает

### Проблема 1: "Нет доступа к инструменту get_chat_messages"

**Причина:** MCP сервер не подключен или DeepSeek не видит Telegram Assistant tools

**Решение:**
1. Убедитесь что `mcp_server/telegram_assistant.py` запущен
2. Проверьте логи bot.py - должно быть: `INFO: Доступно 3 Telegram Assistant MCP tools`
3. Перезапустите бота

### Проблема 2: "Следующий запуск: -"

**Причина:** Старая версия кода без исправления

**Решение:**
1. Убедитесь что изменения применены в `scheduler/manager.py:192-201`
2. Перезапустите бота
3. **Удалите старых ассистентов** и создайте новых

### Проблема 3: Команда `/delete_assistant` не найдена

**Причина:** Команды не зарегистрированы

**Решение:**
1. Проверьте что `scheduler_manager` инициализирован
2. Проверьте логи: `INFO: Команды управления ассистентами зарегистрированы`
3. Перезапустите бота

## 🎯 Полный сценарий тестирования (5 минут)

```bash
# 1. Создать ассистента
/telegram_assistant @test_channel

# 2. Дождаться первоначальной сводки (10-30 сек)
# Проверить: сводка содержит реальные данные

# 3. Проверить список
/list_assistants
# Проверить: показано время следующего запуска

# 4. Создать ещё одного ассистента
/telegram_assistant @another_channel

# 5. Проверить список (должно быть 2)
/list_assistants

# 6. Удалить одного
/delete_assistant @test_channel

# 7. Проверить список (должен остаться 1)
/list_assistants

# 8. Удалить всех
/delete_all_assistants
# Должно показать предупреждение

/delete_all_assistants confirm
# Должно удалить

# 9. Проверить список (должно быть 0)
/list_assistants
```

**Ожидаемое время:** 2-3 минуты + время ожидания сводок
