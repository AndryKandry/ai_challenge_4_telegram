# Реализация системы цитирования и реранкинга для RAG в DeepSeek

## Обзор

В рамках данной задачи была полностью реализована система цитирования источников и механизм реранкинга для RAG-системы, используемой с DeepSeek. Система обеспечивает обязательное указание источников в ответах модели, что повышает доверие к информации и позволяет пользователям проверять достоверность данных.

## Реализованные компоненты

### 1. Механизм реранкинга (`src/embeddings/reranker.py`)

**OllamaReranker** - основной реранкер на основе cross-encoder моделей:
- Использует модели из Ollama (bge-reranker-base)
- Обеспечивает точную оценку релевантности
- Поддерживает автоматическую загрузку моделей
- Включает кэширование запросов для оптимизации

**SimpleReranker** - fallback реранкер на основе эвристик:
- Комбинирует косинусное сходство и фактор длины
- Быстрый и надежный
- Не требует дополнительных моделей

### 2. Система цитирования (`src/rag_integration.py`)

**Метаданные для цитирования:**
- Автоматическая нумерация источников
- Извлечение номеров строк из метаданных
- Вычисление релевантности в процентах
- Форматирование имени файла и ID чанка

**Формат ответа:**
```
Ответ модели с цитатами [1,2] и информацией [3].

Источники:
[1] Источник: document.md, чанк chunk_0, строки 1-15, релевантность: 95%
[2] Источник: guide.txt, чанк chunk_1, строки 20-35, релевантность: 87%
[3] Источник: api.txt, чанк api_chunk_2, строки 40-55, релевантность: 82%
```

### 3. Интеграция с DeepSeek (`providers/deepseek_provider.py`)

**Метод `generate_response_with_sources()`:**
- Автоматическое обогащение запросов RAG
- Создание промптов с требованиями цитирования
- Добавление отформатированных источников к ответу
- Обработка ошибок и fallback

### 4. Расширенная конфигурация (`config/embeddings_config.yaml`)

**Настройки реранкинга:**
```yaml
reranker:
  type: "simple"  # или "ollama"
  params:
    weight_similarity: 0.7
    weight_length: 0.3
    model_name: "bge-reranker-base"  # для Ollama
```

**Настройки цитирования:**
```yaml
citation:
  enabled: true
  default_sources_count: 5

deepseek_integration:
  rag_keywords:
    - "документация"
    - "как работает"
    - "сумрак 2096"
    # ... 179 ключевых слов
```

## Пайплайн обработки

1. **Анализ запроса** - проверка ключевых слов RAG
2. **Семантический поиск** - получение релевантных документов
3. **Реранкинг** - улучшение сортировки (опционально)
4. **Обогащение метаданными** - добавление данных для цитирования
5. **Форматирование промпта** - включение требований цитирования
6. **Генерация ответа** - запрос к DeepSeek
7. **Добавление цитат** - форматирование финального ответа

## Улучшения производительности

- **Кэширование эмбеддингов** - уменьшает время поиска
- **Batch реранкинг** - параллельная обработка документов
- **Оптимизированные промпты** - контроль длины контекста
- **Fallback механизмы** - надежность при недоступности компонентов
