# Руководство по использованию RAG в Telegram боте

## Описание

RAG (Retrieval-Augmented Generation) интегрирован в Telegram бота и работает **только с DeepSeek провайдером** в **текстовом режиме**. Система автоматически обогащает запросы пользователя контекстом из проиндексированных документов.

## Возможности

- ✅ Автоматическое обнаружение запросов, требующих RAG
- ✅ Семантический поиск по документам
- ✅ Обогащение промптов релевантным контекстом
- ✅ Отображение использованных источников пользователю
- ✅ Работает только с DeepSeek в текстовом режиме

## Как это работает

### 1. Триггеры RAG

RAG активируется автоматически, когда в сообщении пользователя встречаются ключевые слова:

- "документация"
- "как работает"
- "инструкция"
- "руководство"
- "что такое"
- "объясни"
- "покажи пример"
- "как использовать"
- "расскажи про"
- "как настроить"
- "как запустить"
- "команды"
- "api"
- "установка"

### 2. Процесс обогащения

1. Пользователь отправляет сообщение с ключевым словом
2. Система определяет, нужен ли RAG
3. Выполняется семантический поиск по индексу документов
4. Топ-3 наиболее релевантных чанка добавляются в контекст
5. DeepSeek получает обогащенный промпт
6. Пользователь видит ответ + список использованных источников

### 3. Отображение источников

**В текстовом режиме** (команда `/text`) после ответа отображается:

```
📚 **Использованные источники RAG:**
1. `getting_started.md` (релевантность: 0.73)
2. `bot_overview.md` (релевантность: 0.71)
3. `api_keys.txt` (релевантность: 0.68)
```

**В JSON/XML режимах** источники НЕ отображаются.

## Использование

### Шаг 1: Переключитесь на DeepSeek

```
/deepseek
```

### Шаг 2: Убедитесь, что активен текстовый режим

```
/text
```

### Шаг 3: Задайте вопрос с ключевым словом

Примеры запросов, которые активируют RAG:

- "Как запустить бота?"
- "Расскажи про команды бота"
- "Покажи пример использования"
- "Как настроить API ключи?"
- "Что такое температура в LLM?"

### Примеры НЕ активирующих RAG:

- "Привет!"
- "Какая погода?"
- "Расскажи анекдот"

## Настройка RAG

Настройки находятся в файле `config/embeddings_config.yaml`:

```yaml
# Настройки интеграции с DeepSeek
deepseek_integration:
  context_chunks: 3              # Количество чанков в контексте
  max_context_tokens: 2000       # Максимум токенов контекста
  context_template: |            # Шаблон форматирования
    Контекст из документации:
    ---
    {context}
    ---

    Вопрос пользователя: {query}

  # Ключевые слова для автоматического использования RAG
  rag_keywords:
    - "документация"
    - "как работает"
    # ... и другие
```

### Параметры поиска

```yaml
search:
  top_k: 5                      # Количество результатов
  min_similarity: 0.5           # Минимальное сходство (0-1)
  cache_queries: true           # Кэширование запросов
  cache_ttl: 3600               # Время жизни кэша (секунды)
```

## Индексация документов

### Добавление новых документов

1. Поместите файлы (`.md`, `.txt`) в директорию `rag_docs/`
2. Запустите индексацию:

```bash
python manage_index.py index --source rag_docs
```

### Проверка индекса

```bash
# Статистика
python manage_index.py stats

# Поиск (тест)
python manage_index.py search "как запустить бота"
```

### Очистка индекса

```bash
python manage_index.py clear
```

## Тестирование

Запустите тестовый скрипт:

```bash
python test_rag_integration.py
```

Тест проверяет:
- Инициализацию RAG Manager
- Статистику индекса
- Поиск по документам
- Определение необходимости RAG
- Обогащение сообщений
- Форматирование источников

## Ограничения

1. **RAG работает только с DeepSeek** - не поддерживается для OpenAI и Yandex GPT
2. **Только текстовый режим** - в JSON/XML режимах источники не отображаются
3. **Требуется Ollama** - для генерации эмбеддингов должен быть запущен Ollama с моделью `bge-m3`
4. **Триггеры на русском** - ключевые слова должны быть на русском языке

## Отладка

### Проверка логов

При использовании RAG в логах будут сообщения:

```
INFO - RAG Manager инициализирован
INFO - DeepSeek Provider: RAG integration enabled
INFO - RAG triggered by keyword: 'команды'
INFO - Message enriched with 3 RAG sources
```

### Частые проблемы

**Проблема**: RAG не активируется

**Решения**:
- Проверьте, что используется DeepSeek (`/deepseek`)
- Убедитесь, что режим текстовый (`/text`)
- Добавьте ключевое слово в запрос ("как", "что такое", "команды" и т.д.)

**Проблема**: "Ollama is not available"

**Решения**:
```bash
# Запустите Ollama
ollama serve

# В другом терминале загрузите модель
ollama pull bge-m3
```

**Проблема**: Источники не отображаются

**Решения**:
- Проверьте режим вывода - должен быть `/text`
- Проверьте, что используется DeepSeek
- Убедитесь, что в индексе есть документы (`python manage_index.py stats`)

## API для разработчиков

### Использование RAG Manager напрямую

```python
from src.rag_integration import RAGManager

# Инициализация
rag = RAGManager()

# Поиск контекста
results = rag.search_relevant_context("как запустить бота", top_k=3)

# Обогащение сообщения
enriched_message, sources = rag.enrich_message_with_rag("команды бота")

# Форматирование источников
sources_info = rag.format_sources_info(sources)

# Статистика
stats = rag.get_statistics()
```

## Заключение

RAG интеграция значительно улучшает качество ответов DeepSeek, предоставляя актуальную информацию из документации. Система автоматически определяет, когда нужен контекст, и прозрачно отображает использованные источники пользователю.
