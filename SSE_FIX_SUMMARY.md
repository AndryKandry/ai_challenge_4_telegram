**Дата:** 18 ноября 2025

## 📋 Что было сделано

### 1. Диагностика проблемы ✅
- Проверен запущенный MCP сервер на порту 8000
- Протестирован SSE endpoint с помощью curl
- Проанализированы логи клиента и сервера
- Обнаружено, что сервер **отправляет** ответы, но клиент их **не обрабатывает**

### 2. Анализ корневой причины ✅
**Проблема:** ClientSession создавался, но `__aenter__()` не вызывался.

**Последствия:**
- `_receive_loop` не запускался (он стартует в `__aenter__()`)
- Сообщения от сервера попадали в `read_stream`, но никто их не читал
- `send_request()` бесконечно ждал ответа, который никогда не приходил
- Через 30 секунд срабатывал timeout

**Код до исправления (mcp_client.py:159):**
```python
self.session = ClientSession(self.read_stream, self.write_stream)
await self.session.initialize()  # ❌ _receive_loop не запущен!
```

### 3. Внесенные исправления ✅

#### Файл: `mcp_client.py`

**Изменение 1:** Метод `_connect_stdio()` (строка 131)
```python
# Вход в контекст сессии (запускает _receive_loop)
await self.session.__aenter__()
```

**Изменение 2:** Метод `_connect_http()` (строка 168)
```python
# Вход в контекст сессии (запускает _receive_loop)
await self.session.__aenter__()
```

**Изменение 3:** Метод `disconnect()` (строка 254)
```python
# Закрытие сессии (выход из контекста)
await self.session.__aexit__(None, None, None)
```

## 🔍 Детали для разработчиков

### Архитектура MCP Client Session

```
ClientSession
    ├── __aenter__()              # 🔑 Запускает _receive_loop
    │   └── start_soon(_receive_loop)
    │
    ├── initialize()               # Отправляет initialize request
    │   └── send_request()
    │       ├── POST /messages/    # Отправка
    │       └── wait(response)     # Ожидание ответа от _receive_loop
    │
    ├── _receive_loop()            # 🔑 Обрабатывает входящие сообщения
    │   └── async for message in read_stream:
    │       └── response_streams[id].send(message)  # Доставка ответа
    │
    └── __aexit__()               # Корректное завершение
```

### Важно!

**Без вызова `__aenter__()`:**
- `_receive_loop` не запускается
- Клиент становится "глухим" к серверу
- Все `send_request()` зависают в ожидании

**С вызовом `__aenter__()`:**
- `_receive_loop` запускается в фоне
- Все ответы от сервера обрабатываются
- Система работает корректно
