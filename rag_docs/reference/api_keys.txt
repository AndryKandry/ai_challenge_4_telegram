Получение API ключей для различных провайдеров

=== OpenAI API Key ===

1. Зарегистрируйтесь на https://platform.openai.com
2. Перейдите в раздел API Keys
3. Создайте новый секретный ключ
4. Скопируйте ключ и сохраните в .env как OPENAI_API_KEY

=== Yandex Cloud API Key ===

1. Зарегистрируйтесь в Yandex Cloud: https://console.cloud.yandex.ru
2. Создайте сервисный аккаунт
3. Назначьте роль "ai.languageModels.user"
4. Создайте API-ключ для сервисного аккаунта
5. Получите ID каталога (folder_id)
6. Добавьте в .env:
   YANDEX_API_KEY=ваш_ключ
   YANDEX_FOLDER_ID=ваш_folder_id

=== DeepSeek API Key ===

1. Зарегистрируйтесь на https://platform.deepseek.com
2. Перейдите в раздел API Keys
3. Создайте новый ключ
4. Добавьте в .env как DEEPSEEK_API_KEY

=== Telegram Bot Token ===

1. Найдите @BotFather в Telegram
2. Отправьте команду /newbot
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен
5. Добавьте в .env как TELEGRAM_TOKEN
