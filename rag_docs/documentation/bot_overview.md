# Обзор Telegram бота с LLM

Этот Telegram бот поддерживает работу с несколькими LLM-провайдерами, включая OpenAI GPT, Yandex GPT и DeepSeek.

## Основные возможности

### Поддержка множественных LLM

Бот позволяет пользователям переключаться между различными языковыми моделями:
- **OpenAI GPT** (gpt-3.5-turbo) - быстрый и качественный, хорошо работает на английском
- **Yandex GPT** (yandexgpt-lite) - отличный для русского языка, локальный сервис
- **DeepSeek** (deepseek-chat) - современная открытая модель с хорошим соотношением цена/качество

### Контекстные диалоги

Бот помнит контекст разговора в рамках сессии. Последние 10 сообщений автоматически передаются в LLM для поддержания контекста диалога.

### Система памяти

Все сообщения сохраняются в базе данных SQLite (agent_memory.db) для долговременного хранения истории диалогов.

## Команды бота

- `/start` - начать работу с ботом
- `/help` - справка по командам
- `/openai`, `/yandex`, `/deepseek` - переключение между моделями
- `/model` - показать текущую модель
- `/session_info` - информация о текущей сессии
- `/new_session` - начать новую сессию
- `/memory_stats` - статистика памяти
